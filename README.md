## 📌 About the project

**DevSorteio** is a web application designed to generate random numbers within a custom minimum and maximum range defined by the user.

Whether you need to draw a giveaway winner, pick a random number for a game, or make a quick decision, **DevSorteio** provides an instant, clear, and responsive interface.

## 💻 Technologies

This project was built using pure web standards (Vanilla Web Tech) without any external dependencies:

* **HTML5** - Semantic layout and input structures
* **CSS3** - Dark theme interface, modern typography, inputs and button styling
* **JavaScript (ES6+)** - DOM manipulation, input validation, and random number generation logic (`Math.random()`)

---

## ⚙️ Features

- [x] Input field to set the **Minimum** value (`Mínimo`)
- [x] Input field to set the **Maximum** value (`Máximo`)
- [x] Instant random integer calculation within the selected interval
- [x] Clean dark mode visual design
- [x] Fully responsive layout for Desktop and Mobile devices

## 👷 Installation & How to Run

Since this project relies strictly on native browser execution, you don't need `Node.js` or `npm`.

### 1. Clone the repository
```bash
$ git clone [https://github.com/VineDevJunior/project-number-sorter.git](https://github.com/VineDevJunior/project-number-sorter.git)
```

2. Open the project
Navigate into the project folder and open index.html in your web browser:
```bash
$ cd dev-sorteio
```
Tip: If you use VS Code, you can open index.html using the Live Server extension.
